# 📊 Система поддержки принятия решений: Метод ЭЛЕКТРА

Современное веб-приложение для многокритериального анализа и выбора оптимальных альтернатив. Проект решает задачу выбора лучшей торговой фирмы на основе экспертных оценок, сочетая строгую математическую модель с интерактивным пользовательским интерфейсом.

## 🚀 Ключевые возможности

*   **Оптимизация по Парето:** Автоматическое исключение доминируемых (заведомо худших) альтернатив из рассмотрения.
*   **Взвешивание критериев (Метод рангов):** Преобразование качественных экспертных оценок в точные числовые веса.
*   **Метод ЭЛЕКТРА:** Расчет матриц индексов согласия и несогласия для попарного сравнения альтернатив.
*   **Интерактивное ядро:** Динамический пересчет итогового списка победителей при перемещении ползунков порогов $c^*$ и $d^*$ в реальном времени.

## 🛠 Технологический стек

*   **Backend:** Python 3, Flask (REST API)
*   **Frontend:** HTML5, Tailwind CSS (Адаптивный дизайн)
*   **Архитектура:** Разделение на слои (Domain, Services, Web) для независимого тестирования и масштабирования.

## 📂 Структура проекта

> Проект построен по принципам Clean Architecture, изолируя математическое ядро от веб-фреймворка.

- `src/domain/` — структуры данных (Альтернативы, Критерии).
- `src/services/` — математические алгоритмы (Парето, Ранги, ЭЛЕКТРА).
- `src/web/` — контроллеры Flask и HTML-шаблоны.
- `main.py` — точка входа в приложение.
